# Build-a-ML-Workflow-For-Scones-Unlimited-On-Amazon-SageMaker

# Dataset
The project utilized a dataset of images representing various types of scones. This dataset was sourced from public repositories or simulated using synthetic data generation techniques. Key characteristics of the dataset include:
Images: High-quality images of scones with varying backgrounds, lighting conditions, and angles.
Labels: Annotated categories for each scone type (e.g., "Blueberry Scone," "Chocolate Chip Scone").
Dataset Size: Approximately thousands of images split into training, validation, and testing subsets.

# Objectives
The primary goals of this project are:
Data Preparation: Perform ETL (Extract, Transform, Load) to clean, normalize, and structure the dataset for machine learning.
Model Training: Train an image classification model using SageMaker's built-in algorithms, optimizing hyperparameters for the best performance.
Deployment: Deploy the trained model as an API endpoint to enable real-time predictions.
Workflow Automation: Design and implement a scalable and automated ML pipeline using AWS Lambda functions and Step Functions.
Monitoring: Continuously monitor the deployed model to ensure consistent performance and reliability.
End-to-End Workflow: Build an end-to-end solution that seamlessly integrates data ingestion, prediction, and result filtration.

# Applications
The "Scones Unlimited" project demonstrates the practical application of machine learning in a real-world scenario, with the following use cases:
Retail Automation: Automate the process of identifying and categorizing bakery items for inventory management and quality control.
Customer Experience: Provide users with an application that predicts and displays the type of scone they are consuming based on an uploaded image.
